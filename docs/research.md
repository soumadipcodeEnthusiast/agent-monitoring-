# Research Framework

## Hypothesis
Adaptive failure discovery can identify meaningful agent failure modes with fewer executions than random or fixed testing.

## Independent Variable
Testing strategy (Random, Fixed, Adaptive).

## Dependent Variables
- Failure discovery efficiency
- Tests-to-failure
- Unique failures discovered
- Failure boundary accuracy

## Baselines
1. **Random**: Samples uniform perturbations.
2. **Fixed**: Sequential pre-defined list.
3. **Adaptive**: Uses discovery engine.

## Ablation Ideas
- without information gain
- without novelty
- without uncertainty
- without failure probability
